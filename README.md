# GREEN-API Telegram Chat

Минимальный React-интерфейс для отправки и получения текстовых сообщений через GREEN-API.

## Запуск

```bash
npm install
npm run dev
```

На стартовом экране укажите `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API. Значения сохраняются только в `sessionStorage` браузера и не попадают в исходный код.

## Как работает

- отправка: `POST /waInstance{idInstance}/sendMessage/{apiTokenInstance}` с полями `chatId` и `message`;
- получение: раз в 3 секунды вызывается `receiveNotification`; обработанное уведомление подтверждается `deleteNotification`;
- отображаются только текстовые уведомления; новый входящий Chat ID автоматически добавляется в список чатов.

## Настройка получения сообщений

В личном кабинете GREEN-API откройте нужный инстанс → «Изменить» и сохраните настройки:

- включено получение уведомлений о входящих сообщениях (`incomingWebhook` / «Входящие сообщения»);
- `webhookUrl` пустой — это важно для технологии HTTP API;
- если доступно отдельное ограничение типов уведомлений, выбраны входящие текстовые сообщения.

После сохранения отправьте новое сообщение на аккаунт подключённого Telegram. Старые сообщения не появятся: HTTP API читает только события, добавленные в очередь после включения уведомлений. Ответ появится в приложении после завершения текущего long-poll запроса и следующей проверки.

## FSD-структура

- `app` — композиция приложения и глобальные стили;
- `pages` — экран подключения и экран чата;
- `widgets` — составные части экрана;
- `features` — сценарии подключения, создания чата, отправки и получения;
- `entities` — модели и UI сообщения/чата;
- `shared` — API-клиент, утилиты и базовые UI-компоненты.
